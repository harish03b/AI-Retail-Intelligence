## 2023-10-24 - ReactMarkdown Inline Components Unmount/Remount Bottleneck
**Learning:** Defining custom React components inline within the `components` prop of `ReactMarkdown` inside a list `map` causes React to unmount and remount the entire message DOM on every re-render (e.g., every keystroke in the chat input). This is because the inline arrow functions create new component types on every render pass, which is a severe performance bottleneck in chat interfaces.
**Action:** Always extract custom components for `ReactMarkdown` outside of the parent component or memoize them using `useMemo`. Similarly, array props like `remarkPlugins={[remarkGfm]}` should be extracted outside the component.
## 2024-05-18 - React Query Default StaleTime Bottleneck
**Learning:** The application instantiates a `QueryClient` globally but relies entirely on React Query's default `staleTime` of 0 ms. When combined with dashboard pages containing numerous independent query widgets (e.g., 6 separate queries for sales, customers, products), every window refocus, component remount, or tab switch triggers a massive burst of redundant background API calls to the backend, causing unnecessary load and slowing down the UI.
**Action:** Always configure a reasonable default `staleTime` (e.g., 5 minutes) when setting up `QueryClient` to allow the cache to absorb redundant requests, especially on pages with many independent widgets.
